# Campaign UI-audit coverage for Tier I ("Lesser") supports

Regenerated by `tools/generate_campaign_audit_coverage.py`. Tracks, for
every currently-covered Tier I (icon, tier) key, whether a human has ever
independently confirmed it through the campaign shadow-ground-truth UI
(`tools/harvest_campaign_review.py`'s `review.html`, recorded in
`assets/campaign_review/manual_truth.json` or promoted into
`assets/harvested_supports/campaign_promotions.json`) -- as opposed to a
key whose only support is the classifier agreeing with itself
(`embedding_confirmed`) or a real `warrant.txt` (`ground_truth`). See
`tools/audit_campaign_truth.py` for the crop-level version of this same
check, and `AI_RAMBLINGS.md` for how this gap was first found and sized.

## Independently audited, all agree

A human read these off the real in-game tooltip during a campaign
encounter and confirmed the same identity the catalog already had.
"Confirmations" splits pixel-identical proof (same exact crop as the
catalog's own reference) from same-identity-different-capture proof (a
fresh roll of the same real support that simply didn't hash-match, most
often real capture-jitter/VFX shimmer -- see this script's own module
docstring) -- both are real independent evidence, just not the same
strength.
